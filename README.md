# Kanban Board API (В процессе)

## Описание

Kanban Board API — это серверное приложение для управления задачами по методологии канбан. Проект позволяет создавать доски, добавлять колонки (например, «К выполнению», «В работе», «Готово») и управлять карточками внутри колонок. Реализовано обновление данных в реальном времени через WebSocket, поддержка нескольких пользователей и надёжная аутентификация.

Основные возможности:
- полноценная аутентификация и разграничение доступа по ролям;
- управление досками, колонками и карточками (CRUD);
- синхронизация в реальном времени через WebSockets;
- хранение данных в PostgreSQL с использованием TypeORM;
- модульная структура с элементами DDD (Domain-Driven Design).

## Технологии

- **Фреймворк**: NestJS
- **Язык**: TypeScript
- **База данных**: PostgreSQL
- **ORM**: TypeORM
- **Real-Time**: WebSockets (Socket.IO)
- **Пакетный менеджер**: npm

## Структура проекта

- `src/`
  - `api/` — контроллеры, DTO и ответы API
  - `common/` — общие ресурсы (например, guards авторизации)
  - `config/` — файлы конфигурации (TypeORM)
  - `modules/` — основная бизнес-логика
    - `auth/` — аутентификация и авторизация
    - `boards/` — управление досками
    - `columns/` — управление колонками внутри досок
    - `cards/` — управление карточками внутри колонок
    - `shared/` — общий код и утилиты
    - `users/` — управление пользователями
  - `main.ts` — точка входа

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/elizabethkru/kanban-board-api.git
   cd kanban-board-api
2. Установите зависимости:

   npm install

## Настройка

Создайте в корне файл `.env` с переменными окружения (пример):

- DB_HOST=localhost
- DB_PORT=5432
- DB_USERNAME=postgres
- DB_PASSWORD=ваш_пароль
- DB_DATABASE=kanban_db

- JWT_SECRET=ваш_секретный_ключ
- JWT_EXPIRES_IN=1d

Укажите свои параметры доступа к PostgreSQL.

## Запуск

- Режим разработки с автоперезагрузкой:

  npm run start:dev

- Сборка и запуск в production:

  npm run build
  npm run start:prod

## Основные эндпоинты API

### Аутентификация

| Метод | Эндпоинт               | Описание                        |
|-------|------------------------|---------------------------------|
| POST  | `/auth/register`       | Регистрация нового пользователя |
| POST  | `/auth/login`          | Вход, получение JWT-токена      |

### Пользователи

| Метод | Эндпоинт           | Описание                   |
|-------|--------------------|----------------------------|
| GET   | `/users/profile`   | Профиль текущего пользователя |

### Доски (Boards)

| Метод   | Эндпоинт           | Описание                   |
|---------|--------------------|----------------------------|
| GET     | `/boards`          | Список всех досок пользователя |
| GET     | `/boards/:id`      | Получить доску по ID       |
| POST    | `/boards`          | Создать новую доску        |
| PATCH   | `/boards/:id`      | Обновить доску             |
| DELETE  | `/boards/:id`      | Удалить доску              |

### Колонки (Columns)

| Метод   | Эндпоинт                       | Описание                       |
|---------|--------------------------------|--------------------------------|
| GET     | `/columns/board/:boardId`      | Все колонки указанной доски    |
| GET     | `/columns/:id`                 | Колонка по ID                  |
| POST    | `/columns`                     | Создать колонку в доске        |
| PATCH   | `/columns/:id`                 | Обновить колонку               |
| DELETE  | `/columns/:id`                 | Удалить колонку                |

### Карточки (Cards)

| Метод   | Эндпоинт                       | Описание                         |
|---------|--------------------------------|----------------------------------|
| GET     | `/cards/column/:columnId`      | Все карточки в колонке           |
| GET     | `/cards/:id`                   | Карточка по ID                   |
| POST    | `/cards`                       | Создать карточку в колонке       |
| PATCH   | `/cards/:id`                   | Обновить карточку                |
| DELETE  | `/cards/:id`                   | Удалить карточку                 |

## WebSocket — события в реальном времени

Подключение: `ws://localhost:3000` (с передачей JWT-токена для аутентификации).

Сервер рассылает события в реальном времени:

- **Доски**
  - `board.created` – добавлена новая доска
  - `board.updated` – доска изменена
  - `board.deleted` – доска удалена

- **Колонки**
  - `column.created` – создана колонка
  - `column.updated` – колонка обновлена
  - `column.deleted` – колонка удалена

- **Карточки**
  - `card.created` – создана карточка
  - `card.updated` – карточка обновлена
  - `card.deleted` – карточка удалена
